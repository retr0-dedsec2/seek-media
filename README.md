# seek-media

Médias des posts de [Seek](https://seek-porfolio.vercel.app) sur Instagram, X et YouTube.

Orbit, l'outil de publication de Seek, dépose ici chaque vidéo ou image validée, pour que Buffer puisse la publier à l'heure prévue. Les fichiers sont retirés quelques semaines après leur publication.

Aucun code ni aucune donnée personnelle dans ce dépôt.
